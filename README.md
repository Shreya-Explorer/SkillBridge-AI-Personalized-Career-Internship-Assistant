# SkillBridge AI

**Personalized Career & Internship Assistant for Students**

SkillBridge AI is a web application that helps students discover the right career path based on their degree, semester, current skills, and career goals. It generates a personalized roadmap, internship readiness score, recommended projects, and a structured 30-day learning plan.

## Problem Statement

Many students struggle to identify which skills they should learn, which internships they can apply for, and how to become job-ready. Existing guidance is often generic and not personalized.

## Solution

SkillBridge AI analyzes student inputs and provides:

* Personalized career roadmap
* Internship readiness score
* Skill-gap analysis
* Recommended portfolio projects
* Internship role suggestions
* 30-day learning plan
* Resume improvement tips

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python Flask
* **Styling:** Custom CSS (responsive design)

## Features

* Responsive UI
* Degree-specific recommendations (BCA, BTech, BCom, MBA, Nursing)
* Goal-based roadmap generation
* Dynamic internship readiness score
* Professional dashboard interface
* Download / Print report support

```bash

python app.py
```

Open `http://127.0.0.1:5000` in your browser.
